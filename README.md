# Post Carousel Hero

A landing page first screen with a stack of social post slides that flicks through one at a time. One HTML file, no build step, no libraries.

## Use it

Open `index.html` in a browser. To put it on your own site, copy the `<style>`, the `.first` block and the `<script>` into your page.

## Make it yours

- **Slides:** put your own images in `slides/` and list them inside `<div class="fan">`. Use 4:5 images (1080x1350 is Instagram's size). Any number of slides works.
- **Words:** change the header, headline, line under it and button in `index.html`.
- **Colors:** edit the variables at the top of the stylesheet. `--glow` and `--sun` color the background light.
- **Speed and layout:** `EVERY` in the script sets the time between flicks. `POS` sets where the front four slides sit.

The animation stops for anyone who has reduced motion turned on.
